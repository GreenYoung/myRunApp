# 体重模块增强 实现提示词

请基于当前 Android 项目，继续增强体重模块。

本次需求聚焦：

```text
体重趋势图独立全屏模块打磨
目标体重线
BMI 展示
体重变化速度
体重记录备注
体重与运动数据联动
```

不要修改已经完成的运动记录、GPS 定位、地图轨迹、运动目标、首页运动卡片等无关功能。

## 1. 当前背景

当前项目已有：

```text
WeightDetailScreen
WeightSummaryCard
WeightRecord
WeightDao
WeightViewModel
Room + Flow
体重新增
体重编辑 / 删除
体重趋势图
趋势图横屏 / 全屏展示能力
7 天 / 30 天 / 90 天 / 全部筛选基础
```

当前体重曲线已经具备基础展示能力，但还可以继续独立化和分析化。

## 2. 总体目标

将体重模块从“记录 + 曲线”增强为“记录 + 趋势分析 + 目标管理 + 运动关联”的健康数据模块。

目标效果：

```text
1. 体重详情页保持简洁
2. 复杂图表进入独立全屏趋势模块
3. 趋势图支持目标体重线
4. 体重记录支持备注
5. 展示 BMI 和体重变化速度
6. 能看到运动量变化和体重趋势之间的关系
```

## 3. 体重趋势图独立全屏模块

### 3.1 页面入口

在体重详情页的趋势图卡片上保留双击进入全屏，或增加一个轻量入口按钮：

```text
查看大图
```

点击后进入独立页面：

```text
WeightTrendFullScreen
```

或：

```text
WeightTrendScreen
```

### 3.2 全屏页面布局

建议结构：

```text
┌──────────────────────────────┐
│ ◯‹        体重趋势            │
│                              │
│ [ 7天 ] [ 30天 ] [ 90天 ] [ 全部 ] │
│                              │
│                              │
│          大尺寸体重曲线        │
│                              │
│                              │
│ 当前 77.20 kg                 │
│ 目标 72.00 kg                 │
│ 距目标 5.20 kg                │
└──────────────────────────────┘
```

横屏时：

```text
只保留返回按钮 + 大图表
隐藏底部复杂信息
尽量让曲线使用完整宽度和高度
```

### 3.3 图表交互

趋势图支持：

```text
点选查看具体记录
展示选中日期
展示选中体重
展示较上次变化
```

交互要求：

```text
点击图表最近的数据点
显示选中态竖线或圆点
卡片底部同步展示数据
空白区域点击不崩溃
```

不要引入大型第三方图表库，优先使用 Compose Canvas。

## 4. 目标体重线

### 4.1 数据来源

目标体重属于用户设置，不属于单条体重记录。

优先使用当前项目已有设置存储方案，例如：

```text
DataStore
```

建议字段：

```kotlin
targetWeightKg: Double?
```

如果当前尚无体重设置仓库，可新增：

```text
WeightGoalRepository
```

### 4.2 UI 展示

在体重趋势图中增加目标体重线：

```text
横向虚线
颜色：绿色或青绿色
标注：目标 72.00 kg
```

要求：

```text
目标线不抢曲线视觉
目标线与体重曲线颜色区分
目标文字不遮挡体重点
无目标体重时不显示目标线
```

### 4.3 目标设置入口

可以在体重详情页增加轻量入口：

```text
目标体重
```

点击弹出目标设置弹窗：

```text
目标体重
[ 72.00 ] kg
```

校验：

```text
目标体重 > 0
建议范围 30.00 kg ～ 300.00 kg
固定保留两位小数
```

## 5. BMI 展示

### 5.1 数据需求

BMI 计算需要身高：

```text
BMI = 体重 kg / 身高 m / 身高 m
```

身高属于用户基础信息，建议保存到设置层：

```kotlin
heightCm: Double?
```

如果没有身高，不显示 BMI 数值，展示：

```text
设置身高后查看 BMI
```

### 5.2 BMI UI

在体重详情页或体重趋势全屏页下方展示：

```text
BMI
24.1
正常 / 偏高 / 偏低
```

分类建议：

```text
< 18.5 偏低
18.5 ～ 23.9 正常
24.0 ～ 27.9 偏高
>= 28 肥胖
```

注意：分类可以按中国常用 BMI 标准，不做医疗诊断，只作为健康参考。

## 6. 体重变化速度

### 6.1 计算方式

支持按当前筛选区间计算：

```text
7 天
30 天
90 天
全部
```

计算：

```text
变化速度 = (最新体重 - 区间第一条体重) / 间隔天数
```

展示建议：

```text
近 7 天：-0.08 kg/天
近 30 天：-0.45 kg/周
```

建议 UI 优先展示：

```text
kg/周
```

因为 kg/天数值太小，不直观。

无足够数据时：

```text
数据不足
```

### 6.2 颜色规则

体重下降：

```text
绿色
↓
```

体重上升：

```text
柔和红色
↑
```

持平：

```text
次级文字
0.00 kg/周
```

不要只依赖颜色表达变化，必须配合箭头。

## 7. 体重记录备注

### 7.1 数据结构

体重记录支持备注，例如：

```text
饮食
训练状态
睡眠
身体状态
```

建议字段：

```kotlin
note: String?
```

如果当前 Room schema 需要迁移，必须新增数据库版本和 Migration，不允许破坏已有数据。

### 7.2 录入 UI

体重记录弹窗中增加备注输入区：

```text
备注
[ 今天晚饭较晚 / 跑后称重 / 状态不错 ]
```

要求：

```text
非必填
最大长度建议 100 字
深色输入框
与现有弹窗输入框风格一致
保存体重时一起保存
编辑体重时回显备注
```

### 7.3 列表展示

体重记录列表中：

```text
有备注时展示一行较小的次级文字
无备注时不占高度
```

不要让列表过于臃肿。

## 8. 体重与运动数据联动

### 8.1 目标

让用户看到：

```text
最近运动量变化后，体重趋势是否有变化
```

第一版不要做复杂算法，只做轻量分析。

### 8.2 数据口径

建议使用：

```text
近 7 天运动总里程
近 7 天运动消耗
近 7 天体重变化
近 30 天运动总里程
近 30 天体重变化
```

### 8.3 UI 展示

在体重详情页增加“运动关联”模块：

```text
运动关联

近 7 天运动 12.30 km
体重变化 -0.40 kg

近 30 天运动 48.20 km
体重变化 -1.20 kg
```

可以增加轻量提示：

```text
最近运动量增加，体重呈下降趋势
```

提示规则只做简单判断：

```text
运动量 > 0 且体重下降：运动后体重呈下降趋势
运动量 > 0 且体重上升：运动增加，但体重仍在上升
运动量 = 0：暂无运动数据关联
体重记录不足：体重数据不足
```

不要做医疗化、绝对化判断。

## 9. 架构建议

### 9.1 数据层

可能新增：

```text
WeightGoalRepository
UserProfileRepository
```

如果项目已有 DataStore 设置仓库，优先复用，不要重复创建多个设置文件。

体重备注如需落库：

```text
WeightRecordEntity.note
Room Migration
```

### 9.2 ViewModel

ViewModel 提供组合后的 UI State：

```kotlin
data class WeightTrendUiState(
    val selectedRange: WeightTrendRange,
    val records: List<WeightRecordUiModel>,
    val targetWeightKg: Double?,
    val selectedRecord: WeightRecordUiModel?,
    val bmi: WeightBmiUiState,
    val changeSpeed: WeightChangeSpeedUiState,
    val exerciseCorrelation: WeightExerciseCorrelationUiState
)
```

Composable 不直接访问 Dao / DataStore。

### 9.3 计算层

建议新增：

```text
WeightStatsCalculator
```

负责：

```text
筛选区间
目标线位置数据
BMI 计算
变化速度计算
运动关联计算
```

便于后续单元测试。

建议拆分：


现有 `WeightDetailScreen` 不要继续无限堆代码，复杂图表优先拆到独立文件。

## 11. 空数据状态

无体重记录时：

```text
趋势图：暂无体重趋势
目标线：如果设置了目标体重，可以展示目标线；否则不展示
BMI：设置身高后查看 BMI
变化速度：数据不足
运动关联：体重数据不足
备注：不展示
```

页面布局保持稳定，不要因为无数据导致高度剧烈变化。

```text
云同步
```
