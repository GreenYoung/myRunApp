## 架构速览

- **单 Activity + Compose**：`MainActivity` 里用 `AppDestination` 做导航，每个 feature 一个 `*Route` 入口（如 `HomeScreen` / `ExerciseRoute` / `WeightRoute`）。
- **feature/home** 首页（今日运动、周目标、体重速览）；**feature/run** 跑步追踪（定位过滤 / 地图渲染 / 前台服务 / 草稿）；**feature/exercise** 运动记录与统计；**feature/weight** 体重记录、趋势。
- **数据层**：Room（`AppDatabase`，各 feature 的 `data/` 下是 Entity/Dao）+ DataStore（`ExerciseGoalRepository` 存周/月目标）。
- **定位链路**：`RunTrackingService`（AMap 定位回调）→ `GpsTrackFilter`（`RunLogic.kt`，精度/速度/断档过滤）→ `RunTrackingStateStore` → 地图与 UI。
- **轨迹渲染**：实时 `AMapRunTrackingMap` + `AMapLiveTrackRenderer`，历史 `AMapTrackPreview` + `drawSportTrack`；共用 `AMapRunTrackRenderer.kt`。
- **统计计算**：`ExerciseStats.kt` 的 `build*` 系列把记录聚合成首页/统计页需要的 UiState。

## 几个关键约定（改代码前先看）

- 轨迹**只收 GPS 点**，网络定位（WiFi/基站）只用于地图蓝点；
- 断档 ≥12s 进恢复期，弦长按本人配速补记（`GpsTrackFilter`）；
- 卡片视觉统一为「渐变 + 1dp 描边 + 大圆角」，新页面请复用现有卡片而不是新造样式；
- debug 包开启文件日志（`FileLogWriter`，2MiB 滚动）。
