# 运动目标设置 v1.0

本次只实现运动详情页底部“运动目标”按钮和目标设置弹窗，不修改已经完成的运动详情、运动记录、日期选择、运动时长选择等功能。

## 1. 底部按钮

运动详情页底部在当前“＋ 增加运动记录”按钮左侧新增：

```text
运动目标
```

布局：

```text
┌──────────────────────────────┐
│ [ 运动目标 ]   [ ＋增加运动记录 ] │
└──────────────────────────────┘
```

要求：

```text
运动目标：次级按钮
＋增加运动记录：主按钮
两个按钮同高
间距约 10dp～12dp
宽度比例约 40% / 60%
```

“运动目标”按钮使用深色背景、绿色描边、绿色文字，形成次操作层级。

## 2. 目标设置弹窗

点击“运动目标”后弹出深色运动风弹窗。

弹窗只包含：

```text
周运动里程
月运动里程
```

不要增加日运动目标、运动次数目标、消耗热量目标、运动时长目标等其它设置。

## 3. 输入规则

周运动里程和月运动里程均支持数字和小数输入，单位固定为：

```text
km
```

单位由 UI 显示在输入区域右侧，不需要用户输入。

保存或再次打开时固定显示两位小数：

```text
30 -> 30.00
35.5 -> 35.50
```

## 4. 默认值

如果用户从未设置运动目标，使用统一默认值：

```text
周运动目标：40.00 km
月运动目标：100.00 km
```

默认值由状态/配置层统一提供，不散落在多个 Composable 中。

## 5. 校验

周运动里程：

```text
> 0
<= 500 km
```

月运动里程：

```text
> 0
<= 2000 km
```

月运动里程必须大于或等于周运动里程。如果输入为空或非法，不写入正式目标数据，并显示明确错误提示。

## 6. 保存和关闭

优先复用当前项目已有弹窗按钮交互。保存成功后关闭弹窗。

点击弹窗外部区域直接关闭弹窗，未保存的修改不覆盖现有目标。

## 7. 数据保存和刷新

运动目标属于用户设置，不写入 `ExerciseRecord`。

使用 DataStore 保存：

```kotlin
weeklyDistanceGoalKm: Double
monthlyDistanceGoalKm: Double
```

目标修改成功后，所有使用运动目标的页面立即更新，特别是首页 `ExerciseSummaryCard`：

```text
weeklyProgress = weeklyDistanceKm / weeklyDistanceGoalKm
monthlyProgress = monthlyDistanceKm / monthlyDistanceGoalKm
```

进度显示最大限制为 100%。数据流保持：

```text
DataStore
↓
Flow
↓
ViewModel
↓
首页运动卡片
```

## 8. 实现范围

本次只实现：

```text
运动目标按钮
周运动里程设置
月运动里程设置
目标持久化
首页周/月目标和进度自动更新
```

不实现 GPS、卡路里目标、运动时长目标、次数目标、AI 推荐或其它设置页面。
