# 运动风返回按钮 v1.0

本次只修改当前详情页顶部返回按钮样式，不修改页面其他已经完成的功能。

目标样式：

```text
圆形深色背景 + 绿色线性返回箭头
```

示意：

```text
┌────────────────────────────────┐
│  ( ‹ )          运动详情        │
└────────────────────────────────┘
```

## 样式要求

返回按钮整体：

```text
圆形
视觉尺寸 40dp～44dp
最小点击区域 44dp × 44dp
不要使用系统默认返回箭头
不要使用白色实心背景
不要使用明显边框
```

按钮背景：

```text
#151E26
```

可以叠加极轻绿色透明层：

```text
#22C55E alpha 0.04～0.08
```

## 返回箭头

箭头使用简洁左向 Chevron：

```text
‹
```

要求：

```text
图标尺寸约 20dp～24dp
图标颜色 #22C55E
水平、垂直居中
视觉轻量
```

## 点击效果

整个圆形区域都可以点击，不只让箭头响应点击。

使用 Compose / Material 自然点击反馈，Ripple 使用低透明度绿色，不增加缩放或发光动画。

点击后执行现有返回逻辑，不修改导航行为。

## 顶部布局

返回按钮左侧与屏幕边缘保留约 16dp。页面标题继续居中，不能因为返回按钮占据左侧空间导致标题明显偏右。

## 组件封装

建议封装可复用组件：

```kotlin
@Composable
fun SportBackButton(
    onClick: () -> Unit
)
```

用于：

```text
WeightDetailScreen
ExerciseDetailScreen
```

避免两套返回按钮实现。

## 验收标准

最终返回按钮必须满足：

```text
圆形深色背景
绿色线性返回箭头
箭头居中
点击区域至少 44dp
与当前深色运动风统一
不使用系统默认大 Back 图标样式
页面标题保持真正居中
体重详情页和运动详情页复用同一返回按钮组件
不修改现有返回逻辑
不修改其他页面内容
```
