# 运动记录轨迹缩略图与详情页实现提示词

请基于当前 Android 项目，实现「运动轨迹保存关联、运动详情页列表轨迹缩略图、运动记录点击进入详情页」功能。

本次目标包含三部分：

```text
1. 确认并完善运动轨迹保存到数据库
2. 运动详情页列表中户外跑步记录展示轨迹缩略图
3. 点击运动记录进入详情页：户外跑步显示全屏地图轨迹，跑步机显示普通数据详情
```

## 1. 当前背景

项目当前已经实现：

- `ExerciseRecordEntity`：普通运动记录表。
- `RunSessionEntity`：户外跑步会话表。
- `RunTrackPointEntity`：GPS 轨迹点表。
- `RunTrackingService`：跑步结束后保存跑步会话和轨迹点。
- `RunTrackDetailScreen`：跑步轨迹详情页。
- `AMapTrackPreview`：高德地图轨迹预览。
- `AMapRunTrackingMap`：实时跑步地图。
- `ExerciseScreen`：运动详情页和运动记录下拉列表。
- `ExerciseRecordItem`：当前运动记录列表项。

当前数据结构中已经存在：

```kotlin
RunSessionEntity(
    val exerciseRecordId: Long,
    ...
)
```

以及：

```kotlin
RunTrackPointEntity(
    val sessionId: Long,
    val latitude: Double,
    val longitude: Double,
    ...
)
```

因此本次应优先复用：

```text
ExerciseRecordEntity.id
↓
RunSessionEntity.exerciseRecordId
↓
RunTrackPointEntity.sessionId
```

不要在未确认必要前新增重复关联字段。

## 4. 数据保存与关联

### 4.1 检查当前保存逻辑

优先检查：

```text
RunTrackingService.saveRun(...)
RunDao
ExerciseDao
```

确认户外跑步结束保存时是否已经：

```text
1. 插入 ExerciseRecordEntity
2. 拿到 exerciseRecordId
3. 插入 RunSessionEntity(exerciseRecordId = exerciseRecordId)
4. 拿到 sessionId
5. 插入 RunTrackPointEntity(sessionId = sessionId)
```

如果当前已经这样保存：

```text
不要新增数据库字段
不要新增迁移
```

如果当前没有建立关联：

优先修正保存流程，让 `RunSessionEntity.exerciseRecordId` 正确指向 `ExerciseRecordEntity.id`。

### 4.2 删除逻辑

删除运动记录时，需要考虑关联轨迹数据。

建议：

```text
删除 ExerciseRecordEntity
↓
如果有关联 RunSessionEntity
↓
删除 RunTrackPointEntity
↓
删除 RunSessionEntity
```

不要留下孤儿轨迹点。

第一版可以在 DAO 中增加明确删除方法，不强制使用外键级联，除非当前项目已经使用外键模式。

## 5. 运动列表 UI 模型

当前 `ExerciseRecordUiModel` 需要扩展，用于判断是否有户外轨迹。

建议增加字段：

```kotlin
val runSessionId: Long? = null
val trackPoints: List<RunTrackPointUiModel> = emptyList()
val hasTrack: Boolean = runSessionId != null && trackPoints.size >= 2
```

如果担心列表查询加载过多轨迹点，可以第一版只加载用于缩略图的点：

```text
最多 80 ~ 120 个点
按顺序抽样
```

但第一版如果数据量不大，可以先直接加载当前记录的轨迹点。

## 6. 运动详情页列表轨迹缩略图

### 6.1 户外跑步记录样式

如果记录类型是户外跑步，并且有轨迹：

```text
┌──────────────────────────────┐
│ ┌──────┐  户外跑步      08-27 │
│ │轨迹线│  1.23 km   17min     │
│ │缩略图│  6'23"/km  120 kcal  │
│ └──────┘                      │
├──────────────────────────────┤
```

左侧轨迹缩略图建议：

- 宽高约 `64dp x 64dp`。
- 圆角 `12dp`。
- 深色背景。
- 使用 Compose Canvas 绘制轨迹线。
- 不嵌入高德 `MapView`。

原因：

- 列表中放多个 MapView 性能和生命周期成本高。
- Canvas 缩略图足够表达“这条记录有轨迹”。
- 点击后进入全屏高德地图详情页查看真实地图。

### 6.2 跑步机记录样式

跑步机记录保持当前样式：

```text
🏃 跑步机                         08-21
5.20 km     33min     6'23"/km     356 kcal
──────────────────────────────────
```

不要因为户外跑步新增缩略图而破坏跑步机列表排版。

### 6.3 无轨迹户外记录

如果记录类型是户外跑步但没有轨迹点：

- 可以使用跑步机同款文本样式。
- 或显示一个深色小占位图，文案不要太多。

建议第一版：

```text
没有轨迹点时走普通文本样式
```

避免空缩略图干扰。

## 7. 轨迹缩略图 Canvas 组件

建议新增：

```kotlin
@Composable
fun TrackThumbnail(
    points: List<RunTrackPointUiModel>,
    modifier: Modifier = Modifier
)
```

绘制规则：

- 过滤非法坐标。
- 过滤 `0.0, 0.0`。
- 不绘制地图底图，只绘制深色背景 + 绿色轨迹线。
- 自动按点的经纬度范围缩放到缩略图区域。
- 起点可用青色小点。
- 终点可用绿色小点。
- 轨迹线使用：

```text
#22C55E
```

- 线宽 `2dp ~ 3dp`。

## 8. 点击进入详情页

### 8.1 列表项点击

当前 `ExerciseRecordItem` 已有 `combinedClickable`，长按用于编辑/删除。

需要加入普通点击：

```kotlin
onClick = { onRecordClick(record) }
```

长按逻辑保持不变。

### 8.2 路由设计

当前项目导航似乎使用 `MainActivity` 中的 `AppDestination` 枚举或状态。

建议新增：

```kotlin
ExerciseRecordDetail(recordId: Long)
```

如果当前简单 enum 不支持参数，可以新增状态：

```kotlin
var selectedExerciseRecordId by remember { mutableStateOf<Long?>(null) }
```

点击列表项后：

```text
selectedExerciseRecordId = record.id
destination = ExerciseRecordDetail
```

详情页根据 recordId 查询记录和关联轨迹。

## 9. 户外跑步详情页

### 9.1 目标样式

户外跑步详情页使用全屏高德地图：

```text
┌──────────────────────────────┐
│ ◯‹                           │
│                              │
│          高德地图             │
│          历史轨迹线            │
│                              │
│ ┌──────────────────────────┐ │
│ │ 户外跑步        2026-08-27 │ │
│ │ 1.23 km       17min       │ │
│ │ 6'23"/km      120 kcal    │ │
│ └──────────────────────────┘ │
└──────────────────────────────┘
```

要求：

- 地图铺满全屏。
- 返回按钮悬浮左上角。
- 运动信息卡片悬浮在地图上方，靠近底部。
- 卡片距离底部保留 `navigationBarsPadding + 20dp ~ 28dp`。
- 地图展示完整历史轨迹。
- 使用高德地图 Polyline。
- 显示起点和终点。

可以复用：

```text
AMapTrackPreview 的地图绘制逻辑
```

但详情页需要全屏地图，不要把地图放到普通 Card 内。

建议新增：

```kotlin
OutdoorRunRecordDetailScreen
OutdoorRunRecordMap
OutdoorRunInfoOverlayCard
```

### 9.2 信息卡片内容

第一版只展示核心数据：

```text
户外跑步        2026-08-27
1.23 km        17min
6'23"/km       120 kcal
```

不要加入太多次级信息。
