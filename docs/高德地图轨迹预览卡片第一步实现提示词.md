# 高德地图轨迹预览卡片第一步实现提示词

请基于当前 Android 项目，实现第一步「TrackPreviewCard 接入高德地图轨迹预览」功能。

本次只改造跑步轨迹详情页中的 `TrackPreviewCard`，将当前 Compose Canvas 简化轨迹预览替换为高德地图预览。不要扩展其他 GPS、运动记录、首页或全屏地图功能。

## 1. 当前背景

项目当前已经实现：

- 前台 GPS 跑步记录。
- 息屏前台服务记录轨迹。
- 运动结束后保存 `RunSessionEntity`。
- 保存轨迹点 `RunTrackPointEntity`。
- `RunTrackDetailScreen` 展示跑步轨迹详情。
- `TrackPreviewCard` 当前使用 Compose Canvas 绘制简化轨迹。
- 高德轻量地图合包 AAR 已接入项目：

```text
app/libs/amap-lite3d-search-location.aar
```

该合包包含：

```text
Lite3dMap
AMapSearch
AMapLocation
```

Manifest 中已经通过占位符配置高德 Key：

```xml
<meta-data
    android:name="com.amap.api.v2.apikey"
    android:value="${AMAP_API_KEY}" />
```

本地 `local.properties` 中已经配置：

```properties
amap.apiKey=036f4fd3f80add0ef4461fed84aafd65
```

## 3. 实现范围

本次只实现：

- `TrackPreviewCard` 内嵌高德 `MapView`。
- 根据已有 `RunTrackPointUiModel` 绘制轨迹 Polyline。
- 显示起点 Marker。
- 显示终点 Marker。
- 自动缩放地图到完整轨迹范围。
- 无轨迹点时保留当前空状态。
- 轨迹点不足 2 个时不要绘制 Polyline。
- 保持当前详情页其余统计卡片、返回按钮、页面间距不变。

本次不要实现：

- 全屏轨迹地图详情页。
- 地图点击放大。
- 地图编辑。
- 轨迹回放动画。
- 猎鹰轨迹纠偏。
- 高德定位替换当前 Android 原生定位源。
- 实时跑步页面地图。
- 导航、路线规划、搜索 POI。
- 新增数据库字段。
- 修改当前 GPS 距离计算逻辑。

## 5. Compose 与 MapView 生命周期

由于高德 `MapView` 是传统 Android View，需要通过 Compose 的 `AndroidView` 接入。

必须正确处理生命周期：

```text
MapView.onCreate
MapView.onResume
MapView.onPause
MapView.onDestroy
```

建议使用：

```kotlin
AndroidView
DisposableEffect
LocalLifecycleOwner
LifecycleEventObserver
remember
```

要求：

- 不要每次重组都重新创建地图对象。
- 页面销毁时释放 MapView。
- 页面暂停/恢复时同步调用 MapView 生命周期。
- 不要在列表高频复用场景中创建多个地图实例。本次 `RunTrackDetailScreen` 只有一个轨迹预览卡片，可以接受内嵌 MapView。

## 6. 地图展示要求

地图区域要求：

- 保持当前卡片深色运动风。
- 地图区域圆角与当前卡片风格统一，约 `16dp`。
- 高度可沿用当前轨迹预览区域高度，必要时微调到 `260dp` 左右。
- 不显示复杂地图控件。
- 不显示默认缩放按钮。
- 不显示比例尺或指南针，除非当前 SDK 默认无法关闭。
- 地图只作为轨迹预览，不做复杂交互。

建议地图配置：

```kotlin
map.uiSettings.isZoomControlsEnabled = false
map.uiSettings.isScaleControlsEnabled = false
map.uiSettings.isCompassEnabled = false
map.uiSettings.isMyLocationButtonEnabled = false
```

## 7. 轨迹绘制规则

已有轨迹点来自：

```kotlin
List<RunTrackPointUiModel>
```

使用字段：

```kotlin
latitude
longitude
```

绘制规则：

- 过滤非法坐标。
- 经纬度为 `0.0, 0.0` 的点不要绘制。
- 轨迹点数量少于 2 个时不绘制 Polyline。
- Polyline 使用绿色强调色：

```text
#22C55E
```

- 线宽建议：

```text
8px ~ 12px
```

- 起点可使用绿色 Marker。
- 终点可使用偏亮色或青色 Marker。
- 如果不想引入图片资源，可以使用高德默认 Marker 加颜色 Hue，或使用简单自定义 BitmapDescriptor。

## 8. 自动缩放规则

地图加载轨迹后应自动缩放到完整轨迹范围。

规则：

- 当有效点数为 1：
  - 地图中心移动到该点。
  - 使用适中的 zoom，例如 `17f`。

- 当有效点数 >= 2：
  - 使用 `LatLngBounds.Builder` 包含所有有效点。
  - 调用 `CameraUpdateFactory.newLatLngBounds(bounds, padding)`。
  - padding 建议 `64px ~ 96px`。

注意：

- 地图尺寸尚未完成布局时，直接调用 `newLatLngBounds` 可能失败。
- 可以在 `MapView.post { ... }` 或地图 view 已布局后再移动镜头。
- 避免每次 Compose 重组都重复添加 Polyline / Marker。

## 9. 状态更新与重复绘制

地图绘制应根据轨迹点变化更新。

建议：

- 使用 `update` block 获取 `MapView`。
- 每次更新前清理旧覆盖物：

```kotlin
map.clear()
```

- 然后重新添加 Polyline、起点、终点。

考虑到当前轨迹详情页点集是历史数据，不是实时高频更新，这种方式足够简单可靠。

不要为本次引入复杂覆盖物 diff 管理。

## 10. 坐标系说明

当前项目保存的轨迹点来自 Android 原生 GPS，通常是 WGS84 坐标。

高德地图使用 GCJ-02 坐标系。

本次第一步可以先直接绘制已有坐标，完成地图展示验证。

但代码中需要预留清晰注释或转换函数入口，例如：

```kotlin
private fun RunTrackPointUiModel.toMapLatLng(): LatLng
```

后续如果发现轨迹相对高德底图有偏移，再单独实现 WGS84 -> GCJ-02 坐标转换。

本次不要引入复杂坐标转换逻辑，避免扩大改动范围。

## 11. 空状态

无有效轨迹点时，保持当前深色空状态，不显示地图。

建议文案：

```text
暂无有效轨迹
```

如果只有 1 个有效点：

- 可以显示地图并居中到该点。
- 不绘制 Polyline。
- 可显示一个定位点 Marker。

## 12. 错误与降级

如果 MapView 初始化失败或高德 Key 无效：

- 页面不能崩溃。
- 轨迹详情页其他统计信息仍要正常显示。
- 可以显示简短错误文案：

```text
地图暂不可用
```

第一版不要求做复杂错误恢复。
